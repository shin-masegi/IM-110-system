※Ref温度補正 (10-15) の動作 (2026-08-02 確定):
- 設定温度は 5/20/35℃ 固定（設定値の変更・保存なし）。画面表示は該当モードの Ref 現在mV。
- mem_sw で該当温度スロットの Ref/受光mVをプローブ統合ストア（Page23/24）へ上書き保存し、
  3スロット揃っていればその場で温度補正式 B/B2/refZR を再フィットして確定する。
  単一温度点だけの後日取り直しも可（残りスロットは保存値を使用）。
- 3スロット揃うまでは捕捉の保存のみ（温度補正は中立 B=B2=0 のまま）。

22.透視度 出荷時3点調整 清水
清水中にプローブ投入し、その受光mVを透視度の出荷時ゼロ (TR_ZR_Ship) として置換する。
清水=減衰ゼロ=理論上∞cm のためフィット点には使わない (2026-08-03 仕様訂正。旧: 理論値100cmの
点として3点計算 — 誤り)。累乗式はスパン(60cm)・中間(30cm)の2点で厳密に決まる。
表示は現在の透視度cm。100cm超は 100 頭打ち + OVERアイコン。

およそ60cm溶液にプローブ投入し、その出力を設定値cm（基準器表示値）とするための3点調整計算。

24.透視度 出荷時3点調整 30cm
およそ30cm溶液にプローブ投入し、その出力を設定値cm（基準器表示値）とするための3点調整計算。

※出荷時3点調整 (16-24) の動作 (2026-08-02 ユーザー仕様確定 — 調整係数 常設モデル):
- 各モードに **ゼロ / スパン / 中間 の3つの調整係数が常に存在**し（「点が無い」状態は無い）、
  新品時から既定式と自己整合する初期値が入っている (probe_store.h STORE_DEF_ADJ3_*)。
  - ゼロ係数  : 0mg/L にする受光mV = ZR (清水時 1750mV 付近。ストア Page4/11/14 の zr が真実源)
  - スパン係数: スパン設定値にする受光mV ＋ 設定値（初期 MLSS 8000 / SS 800 / 透視度 60）
  - 中間係数  : 中間設定値にする受光mV ＋ 設定値（初期 MLSS 4000 / SS 400 / 透視度 30）
- mem_sw で**その画面の係数だけを現在の受光mVで置き換え、常に3点から2次3点調整式
  (透視度は累乗式) を再計算**して即反映し、プローブ flash + 本体ミラーへ確定する。
  ABS は再計算のたびに現在の ZR から導出するため、どの係数をどの順に単独で実施しても正しい。
  - ゼロ実行  (16/19): ZR を置換して再計算。清水中なら表示はただちに 0 になる
  - スパン実行(17/20/23): スパン係数を置換し、**中間係数を「ABSでスパンの1/2」
    (mVでは √(ZR×スパンmV))・設定値1/2 にセットし直して**再計算 → 実質1次式になる
  - 中間実行  (18/21/24): 中間係数のみ置換して再計算 → 2次式（曲線）になる
- 透視度(22)の清水は理論値の通常係数として扱う（ゼロ=TRZR は別枠。スパン実行時の中間セットは
  清水-スパン2点の累乗カーブ上の中点 → 実質2点式）。
