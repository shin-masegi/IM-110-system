#### MLSS,SS補正式の考え方　####
MLSS_05 = 1400mV
MLSS_20 = 1300mV
MLSS_35 = 1200mV
Ref_05 = 950mV
Ref_20 = 900mV
Ref_35 = 850mV

上記4,10,12で取得した6パラメータを使い、MLSSをRef変化に応じて補正する。
清水中だった場合、温度が何度であろうとRefの値からMLSSmVを1300mVにするように補正。

1.補正は%補正とする。加減算方式だと実際のサンプルによる変化でおかしくなる。
2.3点を通る2次式で良いが、計算誤差がでたり複雑な計算になる場合は20度を閾値とした1次式2本でよい。5度側、35度側を20度で切り替える。
3.ZR=MLSS_20ではないはず。そこでオフセット計算すると1.が加減算になり成立しない。
4.6パラメータ初期値1750mVだったら実質全係数が1になり補正無し同等になると思う
5.SS,透視度も同じ考えで、透視度はSSの補正結果を使うでOK
6.フローからスキップで良い。
7.（2の確定 2026-08-05）f は20℃を閾値とした1次式2本に確定（2次式は不採用）。
  Refが捕捉範囲外に出た場合は最寄り区間の直線をそのまま延長して適用する。
8.（4の成立規則）ΔRef がゼロ相当のときは傾きを0として扱う（0除算/NaN防止）。
  傾き0 → f=MLSS_20 の定数 → 補正比1＝補正なし。これにより6パラメータ初期値
  （全1750mV等の同値）は補正なし同等になり、温度を振らずに捕捉した場合も
  補正なしに落ちる（暴走しない）。

補正の適用式（確定）:
  a5  = (MLSS_05 − MLSS_20) / (Ref_05 − Ref_20)
  a35 = (MLSS_35 − MLSS_20) / (Ref_35 − Ref_20)
  f(Ref) = MLSS_20 + a×(Ref − Ref_20)   … a は Ref≧Ref_20 なら a5、Ref＜Ref_20 なら a35
  MLSS補正後mV = MLSS生mV × MLSS_20 / f(Ref現在)   … %補正
  以降の ZR 捕捉・ABS 計算はすべて補正後mVで行う（ZR は MLSS_20 と独立、
  I(0) 内の旧温度補正項 (Ref−refZR)(B+B2·d) は全廃）。SS 同形、透視度は SS の補正後mVを使用。

22.透視度 出荷時3点調整 清水
20℃清水中にプローブを投入して mem_sw 実行。**その時点の現在受光mV (移動平均) を厳密に
そのまま**透視度ゼロとして**現場枠 TR_ZR と出荷時枠 TR_ZR_Ship の両方**に置換する
(SS 画面19 と同じ出荷時経路)。捕捉は他のゼロ捕捉と同じ温度補正後mV — 20℃では生mVと
同値で、それ以外の加工は無い。20℃清水中で実行すれば値は SS_20 (画面07 捕捉値) と実質同値。
**清水 = 理論上 >100cm なので、清水自体はフィット点にしない。** 100cm/60cm/30cm の3点を
「新ゼロ − 初期値のmV差分」の予想点にセットし直して (100cm: −3.7mV / 60cm: −6.7mV /
30cm: −14.9mV = 初期値 ZR 1750.0 と 1746.3/1743.3/1735.1 の差分。2026-08-06 ユーザー指示)、
**3点から2次式 cm = C0 + C1·ABS + C2·ABS² を再フィット**する (ABS_i = log10(TR_ZR_Ship/mV_i))。
- 清水中: ABS ≈ 0 → cm = C0 ≈ 170 >> 100 → **安定して 100.0 + OVER** (境界に乗せると
  99↔OVER をバタつくため、100cm 点はゼロの 3.7mV 下に置く)
- 受光がゼロから 3.7mV 落ちた点で 100.0 表示、以降 60/30 のカーブに沿って低下
- 60/30 の予想点は 23/24 の実測実行で正式置換 (100cm 点の実測画面は無い — 予想点のまま運用)
予想点セットの理由: 既定スパン/中間点は絶対mV (1743.3/1735.1) のため、実測ゼロが 1743.3 を
下回る個体 (LED PWM 収束許容 ±30mV 内で普通に起こる) では「60cm点がゼロより明るい」矛盾
3点になり2次式が破綻する (実機で 28.6cm 張り付き)。
【2026-08-06 仕様変更】従来の「清水既定 1750mV + 累乗式 60/30 2点フィット」を廃止。
既定 1750 は空中1450正規化が前提の値で、SADS 廃止 (出力=生mV) 後は清水受光の絶対値が
個体・LED 依存になるため、この個体の 20℃清水中の実受光を透視度ゼロに使う (handoff
2026-08-05 指示、2026-08-06 現在値の厳密使用に確定)。
測定時は ABS = log10(TR_ZR/温度補正後受光) → 2次式。受光 ≥ TR_ZR は cm > 100 →
100.0 頭打ち + OVERアイコン。>100 判定の基準は捕捉した清水mVそのもの。
表示は現在の透視度cm (小数1桁、23/24 と統一。2026-08-04)。100cm超は 100.0 頭打ち + OVERアイコン。

※出荷時3点調整 (16-24) の動作 (2026-08-02 ユーザー仕様確定 — 調整係数 常設モデル):
- 各モードに **ゼロ / スパン / 中間 の3つの調整係数が常に存在**し（「点が無い」状態は無い）、
  新品時から既定式と自己整合する初期値が入っている (probe_store.h STORE_DEF_ADJ3_*)。
  - ゼロ係数  : 0mg/L にする受光mV = ZR (清水時 1750mV 付近。ストア Page4/11/14 の zr が真実源)
  - スパン係数: スパン設定値にする受光mV ＋ 設定値（初期 MLSS 8000 / SS 1000 / 透視度 60。
    SS は 2026-08-06 800→1000 訂正）
  - 中間係数  : 中間設定値にする受光mV ＋ 設定値（初期 MLSS 4000 / SS 500 / 透視度 30。
    SS は 2026-08-06 400→500 訂正）
- mem_sw で**その画面の係数だけを現在の受光mVで置き換え、常に3点から2次3点調整式
  (透視度も 2026-08-06 から2次式) を再計算**して即反映し、プローブ flash + 本体ミラーへ確定する。
  ABS は再計算のたびに現在の ZR から導出するため、どの係数をどの順に単独で実施しても正しい。
  - ゼロ実行  (16/19): ZR を置換して再計算。清水中なら表示はただちに 0 になる
  - スパン実行(17/20/23): スパン係数を置換し、**中間係数を「ABSでスパンの1/2」
    (mVでは √(ZR×スパンmV))・設定値1/2 にセットし直して**再計算 → 実質1次式になる
  - 中間実行  (18/21/24): 中間係数のみ置換して再計算 → 2次式（曲線）になる
- 透視度(22)の清水はゼロ係数そのもの（TR_ZR/TR_ZR_Ship 両枠 = **実行時の現在受光mV**。
  清水はフィット点にせず、100cm/60cm/30cm 係数を「新ゼロ − 初期値mV差分」(−3.7/−6.7/−14.9mV)
  の予想点に同時セット。2026-08-06 累乗式廃止 → MLSS/SS と同じ3点2次式）。
  スパン実行(23)時は中間係数を
  「100cm点-スパン点の ABS 中点 (mV=√(X100×スパンmV))・設定値 (100+スパン設定値)/2」へ
  セットし直す → 実質1次式。中間実行(24)で2次曲線になる。
