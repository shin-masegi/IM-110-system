### 2026-08-06 (夕) — 透視度 >100cm 調整方法変更 実装 (本体 Ver.0.41 追記・採番据え置き、実機書込済)

**残件② (清水既定1750 の前提見直し) を実装した。真実源 = `adboad.md` 22-24 / `mlss-calc-reference.md` §8-S TR 節。**

- **仕様 (ユーザー指示)**: ADBOAD 画面22 (透視度 清水) を 20℃清水中で実行し、1750mV 既定では
  なく**その時点の現在受光mVを厳密にそのまま** (移動平均、温度補正後mV=20℃では生mVと同値。
  20℃清水中なら SS_20=画面07 捕捉値と実質同値) ゼロへセットし、**100cm/60/30cm の
  3点2次式**を立てる (累乗式廃止 → MLSS/SS と同型に統一)。**清水はフィット点にしない**
  (清水=理論上>100cm。100cm 点はゼロ−3.7mV の理論点) → 清水中は**安定して 100.0 OVER**
  (100.0 境界に乗せると 99↔OVER をバタつく — 実機指摘で解消 2026-08-06)。
- **実装骨子**: ①22 で TR_ZR/TR_ZR_Ship **両枠** = 現在受光mV、100cm/60/30cm 係数を
  「新ゼロ − 初期値mV差分」(−3.7/−6.7/−14.9mV) の予想点へ → 3点2次フィット
  (`tr_refit_ship_quad`)。清水中 cm=C0≈170 → 安定 OVER、>100/OVER 判定基準 = 捕捉清水mV。
  予想点セットは矛盾3点 (実測ゼロ<1743.3 で 60cm点がゼロより明るくなり2次式破綻 →
  28.6cm 張り付き実機不具合 2026-08-06) の根治。SS 出荷時3点 設定初期値 800/400→1000/500 も訂正
  ②スパン(23)実行時の中間セットも MLSS/SS 同型化 (設定値 (100+スパン)/2) ③計算上のクランプ無し

## 2. 現在の測定モデル（現行実装＝1700系・span傾き）

- **プローブ正規化**: `出力mV = 生mV × ADC_SPAN_INI(1700) / ADC_Span`（span傾き正規化）。空中出力ターゲット **1700mV**。
  ※ 一時期 ADZero オフセット方式にしていたが、現行は **span傾き＋SADS 能動化**（`ADC_Zero` オフセットは撤去、`ADC_Span` を使う）。
- **本体計算**: `I(0)=MLSSZR+(Ref−refZR)(B+B2·…)`（Ref温度補正2次）→ `ABS=log10(I(0)/Y0)`（暗時ADZR廃止）
  → ベース（MLSS/SS=出荷時2次式×k_No / TR=累乗）→ スパン校正 `SP_A·f²+SP_B·f+SP_C`。**機差補正 kiza は廃止**。
- **ゼロ基準**: `INI_*_ZR = 1700`（デフォルト）。実値は **AZC（清水ゼロ校正）が上書き**。
- 詳細と式は `docs/mlss-calc-reference.md` を参照（ここでは繰り返さない）。
